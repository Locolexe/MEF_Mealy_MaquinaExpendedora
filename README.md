# MEF_Mealy_MaquinaExpendedora
Maquina expendedora finita Mealy, sobre una maquina expendedora.

# Limitaciones
## Solo acepta monedas de 1,2,5 y 10.
## El limite de saldo es 20 de saldo, aunque puede aceptar hasta un maximo de 39.
## Una vez se dispensa el producto no se puede hacer nada mas que confirmar la entrega.
